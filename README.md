# UR Print FDM

FDM (Fused Deposition Modeling) 3D printing control system for Universal Robots.

## Project Structure

- `ur_print_fdm/` - Main Python package
  - `config/` - Configuration files
  - `core/` - Core functionality (processor, sample library, toolbox)
  - `domain/` - Domain models (trajectory)
  - `estimators/` - G-code estimators
  - `plugins/` - Plugin system
  - `processes/` - Process handlers
  - `robots/` - Robot backend and contracts
  - `samples/` - Sample data and loaders
  - `shared/` - Shared utilities (network)
  - `ui/` - User interface components
  - `tests/` - Test suite

- `URscript/` - UR robot script files
  - Various robot control scripts
