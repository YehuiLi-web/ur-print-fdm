# Operator Atlas

这张图的视觉语言围绕“专业编辑器里的安静辅助”来组织。它不把右侧参考面板当成第二个日志区，而是把它塑造成一块稳定、冷静、持续陪伴用户编写脚本的知识界面。左侧编辑器保持深色、专注、收束；右侧面板则更明亮、更像工程手册的纸面，形成明确分工。

空间上采用“主工作流压深、参考信息抬亮”的对照关系。代码区是操作现场，信息密度高、节奏紧；参考面板是解释层，使用更大的留白、更强的分节和更稳定的边界，让用户在视线右移时迅速从执行状态切换到理解状态。整体必须像经过多轮推敲的工具界面，而不是把 tooltip 放大后的堆砌。

颜色上使用深蓝黑、灰白和少量高亮青蓝，强调“机械臂控制软件”的精密感。高亮色只服务于当前函数、当前参数和当前焦点关系，绝不泛滥。每一处强调都应像被工程师反复打磨过，克制、干净、准确。

排版上强调层级而不是装饰。大标题只负责定性，区块标题负责定位，正文负责快速查阅。让签名、作用、当前参数、注意事项、相关函数分别拥有自己的信息节奏。最终呈现应像一张经过精心绘制的产品概念板，细节收敛、结构明确、具备专业软件应有的秩序感。
