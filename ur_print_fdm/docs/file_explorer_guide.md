# 文件资源管理器 (File Explorer) 说明文档

## 1. 概述
文件资源管理器是 UR5 打印机控制系统的核心组件之一，提供了一个专业、高效且符合现代 IDE 习惯的项目文件管理界面。

该组件采用了 **VSCode 风格的一体化设计**，将项目根目录与操作面板深度融合，旨在提供极致的视觉体验和操作便捷性。

---

## 2. 核心界面设计

### 2.1 一体化根节点 (Unified Root)
传统的“标题栏”已被移除，取而代之的是一个智能的**项目根节点**：
- **视觉融合**：根节点与下方文件树完美对齐，拥有相同的缩进和背景风格。
- **动态图标**：
  - 左侧：统一的折叠/展开箭头（SVG 渲染）。
  - 右侧：**悬浮式功能工具栏**（新建文件/文件夹、刷新、折叠）。
- **状态感知**：当未打开项目时显示 "NO FOLDER OPENED"，打开项目后显示大写加粗的项目名称（如 **PROJECT_ROOT**）。

### 2.2 视觉风格 (UI/UX)
- **深色主题**：基于 `#2b2b2b` 的专业深色背景，减少视觉疲劳。
- **SVG 矢量图标**：
  - 全面采用 SVG 格式图标，确保在高分屏下清晰锐利。
  - 图标颜色统一适配为浅灰色 (`#cccccc`)，保持视觉一致性。
- **透明交互**：
  - 功能按钮默认背景透明，仅在鼠标悬停时显示深灰色背景 (`#3e3e42`)。
  - 根节点背景透明，消除了突兀的色块感。
- **精细排版**：
  - 统一的 16px 缩进。
  - 优化的行高与内边距 (`padding: 4px`)。
  - 专业的 Tooltip 提示框（深色背景 + 白色文字 + 细边框）。

## 3. 功能特性

### 3.1 基础文件操作
| 功能 | 触发方式 | 说明 |
| :--- | :--- | :--- |
| **打开文件** | 双击文件 | 在中央编辑器中打开脚本文件 (.script, .py 等)。 |
| **折叠/展开** | 点击左侧箭头 | 切换文件夹的显示状态，根节点同样支持。 |
| **新建文件** | 根节点按钮 `+` / 右键菜单 | 创建新的脚本文件，自动添加 `.script` 后缀。 |
| **新建文件夹** | 根节点按钮 `📂` / 右键菜单 | 创建新的子目录。 |
| **刷新** | 根节点按钮 `🔄` / F5 | 重新扫描磁盘变动并更新视图。 |
| **全部折叠** | 根节点按钮 `🔼` | 一键折叠根节点下的所有子文件夹。 |

### 3.2 右键菜单 (Context Menu)
在文件或文件夹上点击右键，可呼出增强型菜单：
- **打开**：在编辑器中打开（仅文件）。
- **新建脚本**：在当前目录下创建文件。
- **新建文件夹**：在当前目录下创建文件夹。
- **重命名** (F2)：修改文件或文件夹名称。
- **删除** (Delete)：安全删除文件（支持确认提示）。
- **复制路径**：将文件绝对路径复制到剪贴板。
- **在资源管理器中打开**：打开系统原生的文件浏览器窗口。
- **查找文件...**：快速搜索项目内的文件。

### 3.3 快捷键索引
| 快捷键 | 功能 |
| :--- | :--- |
| **F2** | 重命名当前选中项 |
| **F5** | 刷新项目视图 |
| **Delete** | 删除当前选中项 |
| **Ctrl + N** | 新建脚本文件 |
| **Ctrl + Shift + N** | 新建文件夹 |
| **Enter** | 打开选中的文件 |
| **Ctrl + C** | 复制文件（内部剪贴板） |
| **Ctrl + V** | 粘贴文件 |

## 4. 技术实现 (For Developers)

- **核心类**：`FileExplorerWidget` (继承自 `QWidget`)
- **文件树组件**：`QTreeWidget`
- **图标管理**：`IconManager` (支持 SVG 渲染与缓存)
- **样式管理**：`ui/theme.py` (全局 QSS) + 局部样式覆盖

### 关键机制
1.  **自定义 ItemWidget**：
    根节点不是普通的 `QTreeWidgetItem` 文本，而是通过 `setItemWidget` 嵌入了一个包含 `QLabel` 和 `QToolButton` 的复合 `QWidget`，从而实现了“标题栏融合”效果。
2.  **SVG 渲染**：
    使用 `PyQt6.QtSvg.QSvgRenderer` 将 SVG 文件动态渲染为 `QIcon`，解决了 Qt 默认对 SVG 颜色控制不足的问题。
3.  **样式层叠**：
    通过精细调整 `QTreeWidget::branch` 样式，实现了所有层级（包括子文件夹）统一使用自定义箭头图标。
