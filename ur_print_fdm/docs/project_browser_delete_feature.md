# 项目浏览器删除功能优化说明

## 概述
为项目浏览器组件添加了文件删除功能，包括右键菜单、删除确认对话框和键盘快捷键。

## 主要功能

### 1. 右键删除功能
- 在项目浏览器中右键单击文件
- 菜单中新增"🗑️ 删除"选项
- 点击选项可删除选定文件

### 2. 删除确认对话框
- 删除文件前显示确认对话框
- 明确提示将要删除的文件名
- 防止意外删除重要文件

### 3. 不再提示选项
- 确认对话框中包含"下次不再提示"复选框
- 勾选后将不再显示确认对话框
- 设置保存在配置中，下次启动仍有效

### 4. 键盘快捷键
- 支持 Delete 键删除选定文件
- 快速操作，提升工作效率

### 5. 配置管理
- 删除确认设置保存在配置文件中
- 路径: `project.confirm_deletion`
- 默认值: `True` (需要确认)

## 技术实现

### DeleteConfirmationDialog 类
- 继承自 QDialog
- 自定义删除确认对话框
- 包含文件名显示、确认按钮和不再提示复选框

### 项目浏览器更新
- `show_context_menu`: 添加删除菜单项
- `delete_file`: 实现文件删除逻辑
- `tree_keyPressEvent`: 处理键盘事件
- `handle_delete_key`: 处理删除键

### 删除逻辑
1. 检查是否需要确认（从配置读取）
2. 如果需要确认，则显示确认对话框
3. 根据用户选择执行删除操作
4. 从文件系统和树形结构中删除文件
5. 记录日志并更新界面

## 使用方法

### 方式1: 右键菜单
1. 在项目浏览器中右键单击目标文件
2. 选择"🗑️ 删除"
3. 在确认对话框中确认删除

### 方式2: 键盘快捷键
1. 选中目标文件
2. 按下 Delete 键
3. 在确认对话框中确认删除

### 不再提示
- 在确认对话框中勾选"下次不再提示"
- 后续删除将不再显示确认对话框

## 安全特性

1. 删除前确认，防止误删
2. 仅删除选定的单个文件
3. 文件删除后无法恢复
4. 删除后自动刷新项目视图

## 注意事项

- 删除操作不可逆，请谨慎使用
- 只能删除文件，不能删除文件夹
- 如果勾选"不再提示"，后续删除操作将直接执行
- 请确保在删除前已备份重要文件
