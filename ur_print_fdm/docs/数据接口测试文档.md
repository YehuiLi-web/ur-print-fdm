## 3. 打印时间估算方案

### 3.1 方案A：静态脚本分析（推荐）

**原理**: 解析URScript文件，计算每个运动指令的理论时间

**实现步骤**:

#### Step 1: 解析URScript运动指令
```python
import re

def parse_urscript_movements(script_path):
    """解析URScript中的运动指令"""
    movements = []

    with open(script_path, 'r', encoding='utf-8') as f:
        for line_num, line in enumerate(f, 1):
            # 匹配 movel(pose, a=acc, v=speed)
            match_movel = re.search(r'movel\((.*?),\s*a=([\d.]+),\s*v=([\d.]+)\)', line)
            if match_movel:
                pose_str, acc, vel = match_movel.groups()
                movements.append({
                    'type': 'movel',
                    'line': line_num,
                    'velocity': float(vel),
                    'acceleration': float(acc),
                    'pose': pose_str
                })

            # 匹配 movej(q, speed, acc, async)
            match_movej = re.search(r'movej\((.*?),\s*([\d.]+),\s*([\d.]+)', line)
            if match_movej:
                q_str, speed, acc = match_movej.groups()
                movements.append({
                    'type': 'movej',
                    'line': line_num,
                    'velocity': float(speed),
                    'acceleration': float(acc),
                    'joints': q_str
                })

    return movements
```

#### Step 2: 计算运动时间
```python
import math

def estimate_movel_time(start_pose, end_pose, velocity, acceleration):
    """
    估算线性运动时间
    公式: t = d/v + v/a (梯形速度曲线)
    """
    # 计算欧氏距离
    distance = math.sqrt(sum((e - s)**2 for s, e in zip(start_pose[:3], end_pose[:3])))

    # 加速时间
    t_accel = velocity / acceleration
    # 加速距离
    d_accel = 0.5 * acceleration * t_accel**2

    if distance <= 2 * d_accel:
        # 三角形速度曲线（距离太短，无法达到最大速度）
        return 2 * math.sqrt(distance / acceleration)
    else:
        # 梯形速度曲线
        d_constant = distance - 2 * d_accel
        t_constant = d_constant / velocity
        return 2 * t_accel + t_constant

def estimate_movej_time(start_q, end_q, velocity, acceleration):
    """
    估算关节运动时间
    velocity: rad/s, acceleration: rad/s²
    """
    # 找到最大关节角度变化
    max_delta = max(abs(e - s) for s, e in zip(start_q, end_q))

    t_accel = velocity / acceleration
    d_accel = 0.5 * acceleration * t_accel**2

    if max_delta <= 2 * d_accel:
        return 2 * math.sqrt(max_delta / acceleration)
    else:
        d_constant = max_delta - 2 * d_accel
        t_constant = d_constant / velocity
        return 2 * t_accel + t_constant
```

#### Step 3: 累计总时间
```python
def calculate_total_print_time(script_path):
    """计算脚本总执行时间"""
    movements = parse_urscript_movements(script_path)

    total_time = 0.0
    current_pose = [0, 0, 0, 0, 0, 0]  # 初始位姿（需要从脚本中提取）
    current_q = [0, 0, 0, 0, 0, 0]     # 初始关节角度

    for move in movements:
        if move['type'] == 'movel':
            # 解析目标位姿
            target_pose = parse_pose_string(move['pose'])
            time_delta = estimate_movel_time(
                current_pose, target_pose,
                move['velocity'], move['acceleration']
            )
            total_time += time_delta
            current_pose = target_pose

        elif move['type'] == 'movej':
            target_q = parse_joints_string(move['joints'])
            time_delta = estimate_movej_time(
                current_q, target_q,
                move['velocity'], move['acceleration']
            )
            total_time += time_delta
            current_q = target_q

    return total_time, movements
```

**优点**:
- ✅ 可以在打印前预估时间
- ✅ 不需要修改机器人脚本
- ✅ 可以生成详细的时间线

**缺点**:
- ⚠️ 估算值，存在误差（约5-10%）
- ⚠️ 不考虑blend radius的影响

```python
def insert_progress_markers(script_content, total_lines):
    """
    在脚本中每隔N行插入进度标记
    使用DO7作为进度指示器（0-100%）
    """
    lines = script_content.split('\n')
    marked_lines = []

    marker_interval = max(1, len(lines) // 100)  # 100个进度点

    for i, line in enumerate(lines):
        marked_lines.append(line)

        # 在运动指令后插入标记
        if 'movel(' in line or 'movej(' in line:
            if i % marker_interval == 0:
                progress = int((i / len(lines)) * 100)
                # 使用Modbus寄存器存储进度（0-100）
                marked_lines.append(f'  modbus_set_output_register("PROGRESS", {progress})')

    return '\n'.join(marked_lines)
```

## 4. 代码执行行号追踪方案

### 4.1 问题分析

**UR机器人的限制**:
- ❌ RTDE接口**不提供**当前执行行号的API
- ❌ Dashboard接口**不提供**脚本执行位置
- ❌ 无法通过官方API直接获取

### 4.2 解决方案：插桩标记法

**原理**: 在脚本中插入"里程碑"标记，通过IO状态反推执行位置

#### 实现示例
```python
def instrument_script_with_markers(script_path, output_path):
    """
    在脚本中插入执行标记
    使用DO端口的二进制组合表示行号
    """
    with open(script_path, 'r', encoding='utf-8') as f:
        lines = f.readlines()

    instrumented = []
    marker_id = 0

    for i, line in enumerate(lines):
        instrumented.append(line)

        # 在每个运动指令后插入标记
        if 'movel(' in line or 'movej(' in line:
            # 使用DO0-DO6表示7位二进制（0-127个标记点）
            marker_bits = format(marker_id % 128, '07b')

            for bit_idx, bit_val in enumerate(marker_bits):
                instrumented.append(
                    f'  set_standard_digital_out({bit_idx}, {"True" if bit_val == "1" else "False"})\n'
                )

            marker_id += 1

    with open(output_path, 'w', encoding='utf-8') as f:
        f.writelines(instrumented)

    return marker_id  # 返回总标记数
```

#### 读取标记
```python
def read_execution_marker(driver):
    """读取当前执行标记ID"""
    marker_bits = []
    for i in range(7):
        bit = driver.get_digital_out(i)
        marker_bits.append(1 if bit else 0)

    marker_id = sum(bit * (2**i) for i, bit in enumerate(marker_bits))
    return marker_id

def map_marker_to_line(marker_id, marker_map):
    """将标记ID映射回源代码行号"""
    return marker_map.get(marker_id, -1)
```

**优点**:
- ✅ 可以追踪执行位置
- ✅ 7个DO端口可以表示128个标记点

**缺点**:
- ❌ 需要修改脚本
- ❌ 占用7个DO端口
- ❌ 分辨率有限（最多128个标记点）

### 4.3 替代方案：时间戳推算法

**原理**: 结合静态时间估算和实时运行时间，推算当前执行位置

```python
def estimate_current_line(movements, elapsed_time):
    """
    根据已运行时间推算当前执行的运动指令
    """
    cumulative_time = 0.0

    for i, move in enumerate(movements):
        move_time = move['estimated_time']

        if cumulative_time + move_time > elapsed_time:
            # 当前正在执行这个运动
            progress_in_move = (elapsed_time - cumulative_time) / move_time
            return {
                'movement_index': i,
                'line_number': move['line'],
                'progress': progress_in_move,
                'type': move['type']
            }

        cumulative_time += move_time

    return None  # 已完成
```

**优点**:
- 不需要修改脚本
- 不占用IO资源

**缺点**:
- 估算值，存在累积误差
- 如果机器人暂停/减速，会产生偏差

## 5. 挤出机速度获取方案

### 5.1 当前实现分析

**Modbus寄存器控制** ([core/print_lib.py:46-61](core/print_lib.py#L46-L61)):
```python
def calc_extruder_reg(self, print_speed_mm_s, line_width, layer_height):
    """
    计算挤出机Modbus寄存器值
    公式: 寄存器值 = base_reg + E速度×100
    """
    flow_rate = print_speed_mm_s * line_width * layer_height  # mm³/s
    e_speed = flow_rate / self.filament_area                  # mm/s
    if e_speed > 9.99: e_speed = 9.99
    return int(self.base_reg + round(e_speed * 100))
```

**示例**:
- `base_reg = 4000`
- `e_speed = 1.12 mm/s`
- `寄存器值 = 4000 + 112 = 4112` ← 用户选中的代码

### 5.2 反向解析方案

```python
def decode_extruder_speed(modbus_value, base_reg=4000):
    """
    从Modbus寄存器值反推挤出速度

    Args:
        modbus_value: Modbus寄存器值 (如 4112)
        base_reg: 基准寄存器值 (默认 4000)

    Returns:
        e_speed: 挤出速度 (mm/s)
    """
    if modbus_value < base_reg:
        return 0.0

    speed_encoded = modbus_value - base_reg
    e_speed = speed_encoded / 100.0  # mm/s

    return e_speed

def decode_extruder_flow_rate(modbus_value, line_width, layer_height,
                               filament_diameter=1.75, base_reg=4000):
    """
    从Modbus寄存器值反推体积流量

    Returns:
        flow_rate: 体积流量 (mm³/s)
    """
    e_speed = decode_extruder_speed(modbus_value, base_reg)
    filament_area = math.pi * (filament_diameter / 2) ** 2
    flow_rate = e_speed * filament_area  # mm³/s

    return flow_rate
```

```python
def extract_extruder_speeds_from_script(script_path):
    """
    从URScript中提取所有挤出速度设置
    返回: [(line_num, modbus_value, e_speed), ...]
    """
    speeds = []

    with open(script_path, 'r', encoding='utf-8') as f:
        for line_num, line in enumerate(f, 1):
            match = re.search(r'modbus_set_output_register\("MODBUS_1",\s*(\d+)\)', line)
            if match:
                modbus_value = int(match.group(1))
                e_speed = decode_extruder_speed(modbus_value)
                speeds.append((line_num, modbus_value, e_speed))

    return speeds
```
