快速开始

第一次连机或现场换设备时，先按这个顺序过一遍。

  1. 确认电脑、UR 控制箱、挤出机控制器处于同一局域网。
  2. 机器人默认常见网段是 192.168.137.x，电脑 IP 需要落在同网段。
  3. 先启动机器人并进入遥控模式，再运行软件建立连接。
  4. 在资源管理器中打开 G-code 或 URScript 文件，必要时先做脚本转换。
  5. 连接成功后再开始上传、装载或执行，不要在未确认连接状态时直接发脚本。
建议操作顺序

打开文件 -> 检查 TCP/Feature -> 连接机器人 -> 做打印前检查 -> 再开始执行。

工艺与轨迹

汇总影响打印质量和运动结果的关键说明。

运动方式怎么选

  • movej 适合起始位、回零位、空移切换。
  • movel 适合短距离直线段和层间切换。
  • movep 更适合连续打印轨迹，能利用混合半径让拐角更顺。

TCP / Feature 的核心理解

  • Feature 是相对 Base 的坐标变换，不是单纯的“偏移量”。
  • 喷头下拧以后，优先考虑抬高 Feature 的 Z，而不是盲改原轨迹。
  • 相对移动本质上是相对当前参考系的偏移，参考坐标一变，落点会整体漂移。
拖拽与首层问题通常不是单点故障

优先联动检查首层高度、喷嘴姿态、线宽、温度、速度和冷却风扇，不要只盯一个参数。

故障排查

按照“表象 -> 优先检查项”的方式快速缩小问题范围。

现场表现 优先检查 建议动作
线材拖拽、边缘拉丝明显 首层高度、风扇、温度、速度、线宽 先做首层高度复核，再配合风扇和速度调参。
打印头不出料 白色导管、喷嘴堵塞、加热状态、风扇 先确认导管是否完全插入，再检查喷嘴和加热。
出料一卡一卡 地线接触、挤出齿轮阻力、堵头 先复查地线和齿轮状态，再做堵头排查。
转盘同步不稳定 供电、同步方案、多线程策略 不要默认按理论步长执行，先做单步验证。

硬件与维护

常见机械端与外围设备检查项。

挤出侧

  • 喷嘴通常需要加热后再安装或拆卸。
  • 注意挤出机齿轮声音，异响通常意味着阻力异常或堵头。
  • 手动挤压能出料而自动出料困难时，优先怀疑通道压迫或喷嘴尺寸不匹配。

Modbus / 外设侧

  • 现场修改寄存器逻辑时，先确认外设寄存器定义和方向含义。
  • 转盘与加热共电源时，先确认供电稳定，再谈同步控制。
  • 做外设联动前，先验证单机动作是否稳定，不要直接联机叠加复杂问题。
